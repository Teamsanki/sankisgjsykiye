# TERA SANKI / SANKI MUSIC

Sanki Beats on this artist website is a showcase only. Put ONLY 30-second preview MP3s in `assets/music/`. Never upload full-length master beats here.

Edit `config.js`:
- `sankiBeats.online: true` shows the samples; `false` shows Coming Soon.
- `officialSiteUrl` is the official marketplace URL.
- `aiAgentUrl` is the AI bargaining agent URL.
- `samples` controls beat title, genre, BPM, key and preview filename.

The page attempts to deter right-click and common inspect shortcuts, but browser inspection cannot be fully disabled. Security comes from not hosting full files here. The 30-second playback cap is client-side convenience; upload an actual 30-second preview file for robust enforcement.

Static HTML/CSS/JS. Upload repository root to GitHub Pages or Cloudflare Pages; no build command.
